# Meeting Summarizer Skill

**Version:** 1.0.0
**Type:** Content Analysis
**Trigger:** Calendar event completion or manual invocation
**Requires Approval:** No

---

## Purpose

Automatically summarize meeting notes, extract action items, and identify key decisions for easy reference and follow-up.

---

## Capabilities

- Parse meeting notes from various formats
- Extract attendees and participants
- Identify key decisions made
- Extract action items with owners
- Summarize main discussion points
- Generate structured summary in markdown
- Save to vault/Done/ for archival

---

## Trigger Conditions

**Automatic:**
- Calendar event marked as completed
- Meeting notes file detected in vault/Inbox/
- Email with subject containing "meeting notes" or "meeting summary"

**Manual:**
- User creates action file with type: meeting_summary
- User invokes via orchestrator

---

## Input Context

**Required:**
- Meeting title
- Date and time
- Attendees list

**Optional:**
- Meeting notes (raw text or structured)
- Recording transcript
- Shared documents or links

**Sources:**
- vault/Inbox/meeting-notes-*.md
- Email body with meeting notes
- Calendar event description

---

## Extraction Logic

**Key Decisions:**
- Look for phrases: "decided", "agreed", "approved", "confirmed"
- Extract decision and context
- Note who made the decision if mentioned

**Action Items:**
- Look for phrases: "will", "should", "needs to", "action item"
- Extract task description
- Identify owner (person assigned)
- Determine deadline if mentioned
- Classify priority (high/medium/low)

**Discussion Points:**
- Group related topics
- Summarize main points (3-5 bullets per topic)
- Preserve important details and numbers

---

## Decision Logic

**When to summarize:**
1. Meeting has concluded (calendar event ended)
2. Meeting notes are available
3. Meeting duration > 15 minutes (skip quick check-ins)

**When to skip:**
1. No notes available
2. Meeting was cancelled
3. Meeting is recurring daily standup (optional: can be configured)

---

## Workflow

1. **Detect Meeting Completion**
   - Calendar watcher detects ended event
   - Checks for associated notes

2. **Parse Notes**
   - Read notes from vault/Inbox/ or email
   - Extract structured information
   - Identify attendees, decisions, action items

3. **Generate Summary**
   - Format as structured markdown
   - Organize by sections
   - Add metadata frontmatter

4. **Save & Notify**
   - Save to vault/Done/
   - Create notification for attendees (optional)
   - Update Dashboard.md with summary count

## Configuration

**Environment Variables (.env):**
```bash
# Skip summarizing recurring meetings
SKIP_RECURRING_SUMMARIES=true

# Minimum meeting duration to summarize (minutes)
MIN_MEETING_DURATION=15

# Auto-email summary to attendees
EMAIL_SUMMARIES=false
```

---

## Error Handling

**No Notes Available:**
- Create minimal summary with attendees and title
- Flag as "Notes not available"
- Log to vault/Logs/warnings/

**Parse Errors:**
- Save raw notes to summary
- Add "[NEEDS REVIEW]" tag
- Log error details

**Missing Attendees:**
- Use "Unknown attendees" placeholder
- Attempt to extract from notes
